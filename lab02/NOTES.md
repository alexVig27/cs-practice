Рабочая папка - текущая директория проекта на диске, в которой мы непосредственно создаем, редактируем и удаляем файлы

Индекс задает содержимое следующего коммита.

Коммит - постоянный снимок проекта в истории Git.



Различие Git и GitHub:

Git - управляет версиями

GitHub - предоставляет размещение репозиториев и средства совместной работы



git diff — сравнивает текущее состояние рабочей директории с индексом. Она показывает всё, что вы изменили, но ещё не успели добавить через команду git add.

git diff --staged - сравнивает состояние индекса с последним коммитом. Она показывает изменения, которые уже подготовлены к сохранению, и войдут в следующий коммит.
